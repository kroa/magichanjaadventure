# 콘텐츠 설계 — 한자 500자 / 지역 / 몬스터 / 업적 (PHASE 0)

---

## 1. 한자 500자를 어떻게 고를 것인가 (핵심 결정)

임의로 500자를 고르지 않는다. **한국어문회 배정한자 급수 체계**를 그대로 채택한다.

| 급수   | 신습 자수 | 누적    |
| ------ | --------- | ------- |
| 8급    | 50        | 50      |
| 7급 II | 50        | 100     |
| 7급    | 50        | 150     |
| 6급 II | 75        | 225     |
| 6급    | 75        | 300     |
| 5급 II | 100       | 400     |
| 5급    | 100       | **500** |

**5급 누적이 정확히 500자다.** 이것을 선택하는 이유:

1. **검증된 난이도 순서** — 수십 년간 초등 한자 교육에서 쓰인 배열이다. 내가 난이도를 임의로 정하는 것보다 정확하다.
2. **외부 목표와 연결된다** — 아이가 게임에서 6급 지역을 깨면 실제로 한자능력검정 6급 범위를 익힌 것이다. 학습의 실효성이 생기고 부모에게 설명이 된다.
3. **게임 구조와 딱 맞는다** — 7개 급수 = 7개 지역 = 7개 보스. 인위적으로 구간을 만들 필요가 없다.
4. **확장 경로가 명확하다** — 4급(750자), 3급(1817자)으로 지역을 이어 붙이면 된다.

> 데이터 정확성은 PHASE 8에서 `npm run test:unit`의 무결성 테스트로 강제한다.
> 개수 500, 중복 0, 필수 필드 공백 0, 음/훈 형식 검증.

## 2. 지역(Area) 설계

지역 = 급수 티어. 아이는 "6급 공부"가 아니라 **"수정 동굴 탐험"**을 한다.

| ID  | 지역명          | 급수   | 자수 | 해금 레벨 | 분위기                    | 보스              |
| --- | --------------- | ------ | ---- | --------- | ------------------------- | ----------------- |
| 1   | **새싹 마을**   | 8급    | 50   | 1         | 햇살, 초록 들판, 작은 집  | 꼬마 도토리 도적  |
| 2   | **반짝 시냇가** | 7급 II | 50   | 3         | 맑은 개울, 조약돌, 물보라 | 물방울 장난꾸러기 |
| 3   | **바람 언덕**   | 7급    | 50   | 6         | 풍차, 흐르는 구름, 민들레 | 구름 뭉치         |
| 4   | **무지개 다리** | 6급 II | 75   | 10        | 무지개, 폭포, 공중 섬     | 무지개 여우       |
| 5   | **수정 동굴**   | 6급    | 75   | 15        | 보라 수정, 빛나는 이끼    | 수정 아기 골렘    |
| 6   | **별빛 신전**   | 5급 II | 100  | 21        | 밤하늘, 기둥, 떠다니는 룬 | 별똥별 요정       |
| 7   | **한자 왕성**   | 5급    | 100  | 28        | 황금 성, 구름 위, 장엄함  | 붓 마왕           |

**해금 조건 = 레벨 도달 AND 직전 지역 한자 습득률 60%**

레벨만 보면 쉬운 한자를 건너뛰고, 습득률만 보면 진도가 막힌다. 둘 다 요구하면
"조금 더 모으면 다음 지역이 열린다"는 명확한 단기 목표가 생긴다.

## 3. 캐릭터

| 클래스          | 컨셉                                 | HP  | 공격력 | 특징                                       |
| --------------- | ------------------------------------ | --- | ------ | ------------------------------------------ |
| **한자 기사**   | 방패에 한자를 새겨 힘으로 밀어붙인다 | 120 | 10     | HP가 높아 틀려도 오래 버틴다 — 저학년 추천 |
| **한자 마법사** | 한자를 마법으로 바꿔 쏜다            | 90  | 14     | 공격력이 높아 빨리 이긴다 — 고학년 추천    |

**밸런스 의도**: 어떤 선택도 "잘못된 선택"이 되면 안 된다.
기사는 실수에 관대하고, 마법사는 잘 맞히면 빨리 끝난다. 둘 다 클리어 가능하다.
성능 차이가 아니라 **플레이 리듬의 차이**로 설계한다.

## 4. 몬스터 디자인 명세

무섭지 않아야 한다는 것이 절대 조건이다. 규칙:

- 눈은 반드시 크고 둥글게, 하이라이트 2개
- 이빨은 있어도 2개 이하, 짧게
- 피격 표정은 "화남"이 아니라 **"당황/어지러움"**
- 몸통은 전부 곡선. 각진 실루엣 금지
- 패배해도 사라지지 않고 **별을 뱅뱅 돌리며 앉는다** (죽음 표현 없음)

| 몬스터            | 모티프                          | 색            |
| ----------------- | ------------------------------- | ------------- |
| 꼬마 도토리 도적  | 도토리 + 작은 복면, 삐뚠 이빨   | 갈색 + 초록   |
| 물방울 장난꾸러기 | 물방울 + 찡긋 눈                | 하늘색        |
| 구름 뭉치         | 뭉게구름 + 볼터치               | 흰색 + 연보라 |
| 무지개 여우       | 둥근 여우 + 무지개 꼬리         | 주황 + 무지개 |
| 수정 아기 골렘    | 말랑한 수정 덩어리              | 보라 + 반투명 |
| 별똥별 요정       | 별 몸통 + 반짝이 꼬리           | 금색 + 하늘   |
| 붓 마왕           | 큰 붓을 든 작은 마왕, 귀여운 뿔 | 진보라 + 금   |

## 6. 학습 루프 (게임 설계의 심장)

```
        ┌──────────────────────────────────────────┐
        │   메인(모험 지도) — "오늘 뭐 하지?"       │
        └───────┬──────────────┬───────────────┬───┘
                │              │               │
        ┌───────▼──────┐ ┌─────▼─────┐  ┌──────▼──────┐
        │ 한자 배우기  │ │   퀴즈    │  │  NPC 대결   │
        │ (신규 획득)  │ │ (복습)    │  │ (지역 보스) │
        └───────┬──────┘ └─────┬─────┘  └──────┬──────┘
                │              │               │
                └──────┬───────┴───────────────┘
                       ▼
              EXP · 콤보 · 도감 · 업적
                       │
                       ▼
              레벨업 → 새 지역 해금
                       │
                       └──────────► 다시 메인으로 (더 많은 선택지)
```

**핵심**: 아이가 "복습"을 하고 있다는 자각 없이 복습하게 만든다.
퀴즈는 이미 배운 한자에서 출제되지만, 아이 입장에서는 "몬스터와 싸우는" 것이다.

**출제 가중치** — 틀린 적 있는 한자, 오래 안 본 한자에 가중치를 준다.
단순 랜덤은 이미 아는 한자만 반복시켜 학습 효율이 떨어진다.

```
weight = 1
       + (wrong_count × 3)          틀린 한자를 자주
       + (경과일 클램프 0~7)         잊을 때쯤 다시
       - (mastery / 25)              완전히 익힌 건 덜
```

## 7. 첫 5분 시나리오 (온보딩)

이 5분이 서비스의 성패를 결정한다.

```
0:00  마법한자탐험대 로고 + 반짝이는 별      ← "게임이다"
0:10  "탐험대에 들어올래?"  닉네임 · 비밀번호만
0:40  기사와 마법사가 손을 흔든다 → 하나 선택 → 앞으로 한 걸음
1:00  캐릭터가 새싹 마을에 등장. "첫 마법 한자를 찾아보자!"
1:20  한자 배우기 → 一 이 빛과 함께 등장  "새로운 한자를 발견!"  +20 EXP
2:00  3자를 배우면 "이제 도적을 물리쳐 볼까?"
2:20  퀴즈 → 정답 → 마법 발사 → 몬스터 당황 → +10 EXP → 콤보!
3:00  EXP 바가 가득 → 암전 → LEVEL UP 연출
3:30  "새로운 지역이 곧 열려!" 도감에 3칸이 컬러로 채워짐
5:00  아이가 스스로 "한자 더 배우기"를 누른다   ← 성공
```

**5분 안에 레벨업을 한 번 경험시킨다.** 레벨 곡선 초반을 완만하게 잡은 이유가 이것이다.
