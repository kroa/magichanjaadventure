# 에셋 라이선스 대장

> 이 프로젝트에 들어가는 **모든** 시각·청각 자원의 출처와 라이선스를 여기에 기록한다.
> 라이선스가 불명확한 리소스는 **사용하지 않는다.** 예외 없다.

이것이 PHASE 0에서 SVG 자체 제작을 택한 가장 큰 이유다.

## 2. 폰트

| 폰트              | 용도               | 라이선스                  | 상업적 사용 | 임베딩 |
| ----------------- | ------------------ | ------------------------- | ----------- | ------ |
| **Jua**           | 제목 / 버튼 / 숫자 | SIL Open Font License 1.1 | 가능        | 가능   |
| **Noto Sans KR**  | 본문 / UI          | SIL Open Font License 1.1 | 가능        | 가능   |
| **Noto Serif KR** | 한자 글리프        | SIL Open Font License 1.1 | 가능        | 가능   |

SIL OFL 1.1 준수 사항:

- 폰트 파일 자체를 **단독 판매하지 않는다** (웹 서비스에 포함하는 것은 허용).
- 수정 시 **원래 이름(Reserved Font Name)을 쓰지 않는다** → 서브셋만 하고 이름은 그대로 두거나,
  이름을 바꾼다. 서브셋 생성 시 이 점을 확인한다(PHASE 19).
- 라이선스 전문을 배포물에 포함한다 → `static/fonts/OFL.txt`.

## 3. 사운드

MVP에서는 **사운드 파일을 포함하지 않는다.** 매니저 구조와 무음 fallback만 구현한다.

추후 추가 시 규칙:

- **CC0 / Public Domain 만 사용**한다 (저작자 표시 의무가 없어 운영이 단순해진다).
- 후보: [kenney.nl](https://kenney.nl) (CC0), [freesound.org](https://freesound.org) 중 CC0 필터
- 추가할 때 이 표에 **파일명 · URL · 라이선스 · 확인 날짜**를 반드시 기록한다.

## 4. 한자 데이터

| 항목                 | 근거                                                                         |
| -------------------- | ---------------------------------------------------------------------------- |
| 한자 500자 선정 기준 | 한국어문회 배정한자 8급~5급 체계 (**사실 정보 / 체계 자체는 저작물이 아님**) |
| 음 · 훈 · 획수       | 일반적 사전 지식. 특정 출판물을 전재하지 않는다                              |
| 예시 단어 · 설명문   | **본 프로젝트 자체 작성** (아이 눈높이 표현으로 새로 씀)                     |

> 특정 교재·사전의 설명문을 그대로 복사하지 않는다. 급수 체계는 사실 정보이나,
> 개별 해설 문장은 저작물일 수 있으므로 **설명은 전부 직접 작성**한다.

---

## 5. 신규 에셋 추가 시 체크리스트

새 리소스를 넣기 전에 아래를 전부 확인하고 이 문서에 기록한다.

- [ ] 라이선스 명칭이 명확한가 (MIT / CC0 / OFL / Apache-2.0 등)
- [ ] 상업적 사용이 허용되는가
- [ ] 저작자 표시가 필요한가 → 필요하면 어디에 표시할 것인가
- [ ] 수정·2차 저작이 허용되는가
- [ ] 재배포(웹 서비스 포함)가 허용되는가
- [ ] 출처 URL과 확인 날짜를 기록했는가

**하나라도 불확실하면 사용하지 않고 직접 만든다.**
